# Damini Wadekar · Data Science Portfolio

**Live site: [daminikw.github.io](https://daminikw.github.io/)**

An interactive portfolio for getting to know me. I'm a recent Master of Data Science graduate from RMIT University (Melbourne), and I like turning messy data into stories people can act on. I'm open to entry-level data and analytics roles.

## What's inside

| Page | What it shows | How you interact with it |
|---|---|---|
| [Home](https://daminikw.github.io/) | Who I am, qualifications, and a few things you won't find on my résumé | A stack of four illustrated "sides of me" (Analyst, Foodie, Designer, Social butterfly) with clickable sparkle hotspots, plus flip cards |
| [Projects](https://daminikw.github.io/projects.html) | Four case files: the problem, my approach, methods, results and tools | A typewriter types out the project list. Click a line to open its case file |
| [Skills](https://daminikw.github.io/skills.html) | 31 skills, each linked to where I've actually used it | A "data kitchen" of skill jars. Pick a jar to see the evidence, or "cook" a project to light up every skill it used |
| [Experience](https://daminikw.github.io/experience.html) | Work, volunteering and study milestones | A tram line through my journey. Click a stop (or ride the whole line) to read its ticket |
| [Cover letter](https://daminikw.github.io/cover-letter.html) | A general cover letter, plus a 30-second version | Open the sealed envelope to read it |

## Featured projects

- **Enhancing PresX with video-based presentation analysis** (industry capstone with Xolvit Pty Ltd, 2026). I was Phase 2 Lead for the frontend video-recording feature of an AI presentation coach scoring 16 delivery criteria with Google Gemini 2.5 Flash. 100% completion across 9 benchmark tests.
- **Olist repeat-purchase propensity analysis** (solo, 2026). SQL schema over 99,441 real e-commerce orders, cohort and RFM analysis, logistic regression vs XGBoost evaluated with PR-AUC, SHAP explanations and a Power BI dashboard.
- **AWS music subscription app: three backends compared** (team of 3, RMIT Cloud Computing, 2026). The same Flask app deployed on EC2, ECS Fargate and API Gateway + Lambda. I led the serverless build, built the frontend and wrote the documentation.
- **Forecasting Australian monthly dwelling approvals** (solo, RMIT Time Series). A SARIMA(2,1,2)(0,1,1)₁₂ + GARCH(1,1) model in R on 513 months of ABS data, read against the National Housing Accord targets.

## Tech and design

- **Built with:** plain HTML, CSS and JavaScript. No frameworks and no build step. `dc-lite.js` is a small script that fills in each page's content and handles the interactions while keeping the animations smooth.
- **Fonts:** Playfair Display (headings) and Open Sans (body), via Google Fonts. Courier Prime on the typewriter paper.
- **Colours:** Buttermilk `#FFF2BA`, Whipped Butter `#F2E6B3`, Midnight Blue `#0F3C65`, Cookie Crumble `#4B2E21`, with mustard `#E8B931` accents.
- **Illustrations:** my own avatars, generated with Google Gemini.
- **Hosting:** GitHub Pages.

## Files

```
index.html          Home
projects.html       Projects (typewriter + case files)
skills.html         Skills (data kitchen)
experience.html     Experience (tram line)
cover-letter.html   Cover letter (envelope)
404.html            Sends unknown links back to Home
dc-lite.js          Small script that renders each page and runs the interactions
img/                Avatar illustrations
```

To run it locally, download the repository and open `index.html` in a browser, or run `python -m http.server` in the folder and visit `http://localhost:8000`.
